# 《童趣游戏盒》游戏玩法设计文档

> 版本：v1.0 ｜ 日期：2026-10-28 ｜ 配套文档：《儿童小游戏APP计划书》
> 本文档为 19 款游戏的**玩法规格书**，供开发时逐个对照实现。所有游戏遵循第 0 章全局原则。

---

## 0. 全局玩法原则（所有游戏强制遵守）

1. **无失败惩罚**：任何游戏不允许"游戏结束=前功尽弃"，低龄段只允许正反馈。
2. **单局 1~3 分钟**：局内随时可暂停退出，退出不丢进度（进度即玩即存）。
3. **零文字门槛**：所有引导用图标、语音、动画高亮，不依赖识字。
4. **统一结算**：星星（1~3）+ 大按钮"再玩一次 / 回大厅"，格式全 App 唯一。
5. **难度配置统一模板**：每个游戏对外暴露 3 个家长可调开关——`速度`、`时间限制`（默认关）、`提示辅助`（默认开）。
6. **触控热区 ≥ 48×48px**，点击判定比视觉图形外扩 8px。

## 一、反应点击类

### 1. 打地鼠（Whack Mole）｜3+

**玩法规则**：九宫格洞口中地鼠随机冒头，点击即得分。金地鼠 +2 分，戴炸弹道具的地鼠不能点（点了所有地鼠缩回 2 秒）。
**核心循环**：地鼠冒出 → 孩子点击 → 得分 + 音效 + 地鼠表情反馈 → 下一只冒出。
**难度梯度**：
- 3 岁：同时最多 1 只，停留 2.5 秒
- 5 岁：同时最多 2 只，停留 1.5 秒
- 7 岁：3 只 + 混入炸弹鼠
**计分/结算**：限时 60 秒模式（大龄）与无限模式（默认）二选一；连击 5 次触发"闪电清屏"全屏特效。
**开发核心**：定时器随机位生成 + 位图状态机；命中率统计。
**儿童化要点**：无倒计时默认档；地鼠戴随机可爱头饰；漏掉不扣分无提示。

## 二、记忆与观察类

### 2. 翻牌记忆（Memory Match）｜3+

**玩法规则**：牌面朝下网格，每次翻 2 张，相同则保持翻开，不同则盖回；全部配对成功过关。
**核心循环**：翻第一张 → 翻第二张 → 比较 → 配对（翻开+庆祝动画）/ 不配对（短暂展示后盖回）→ 继续。
**难度梯度**：2×3（3 岁，6 张）→ 3×4 → 4×4 → 6×6（大龄）。
**计分/结算**：按步数评星（如 4×4 下 ≤14 步三星）；不限时。
**开发核心**：洗牌算法（Fisher-Yates）、双翻状态机、防连点锁、配对失败盖回延迟（儿童档 1.5s）。
**儿童化要点**：卡面用自家角色库大图；配对成功播放角色跳出来打招呼的动画（收集感）。

### 3. 找不同（Spot Difference）｜4+

**玩法规则**：两张几乎相同的萌图并排，找出 N 处不同并点击。
**核心循环**：观察 → 点击差异处 → 命中（圈出 + 音效）/ 未命中（图片轻微抖动，无惩罚）→ 全部找出过关。
**难度梯度**：差异数 3 → 5 → 8；图片复杂度递增。
**计分/结算**：不限时；提示按钮点按后在某差异处闪烁 3 秒。
**开发核心**：素材成对图 + 差异点坐标 JSON（热点区域圆形判定，半径 ≥ 32px）；命中去重。
**儿童化要点**：差异主体选大而明显（不是考眼力的成人向）；配专属找茬角色旁白鼓励语音。

## 三、拼图与构建类

### 4. 宝宝爱拼图（Jigsaw）｜3+

**玩法规则**：目标图切分为块，打乱排列，孩子拖动碎块到轮廓正确位置，吸附成功；全部归位播放完整图动画。
**核心循环**：看参考图 → 拖块 → 吸附成功（咔哒声）→ 下一块 → 完成庆祝。
**难度梯度**：2×2 → 3×3 → 4×4 → 6×6；参考图默认常显（可关）。
**计分/结算**：不限时；完成即三星（儿童段不按时间评星）。
**开发核心**：切图 + 打乱（保证非原位）+ 距离阈值吸附（< 24px 自动归位）。
**儿童化要点**：块与块留大间隙；图案选孩子角色库单主体（不要复杂背景）。

### 5. 宝宝搭积木（Block Builder）｜3+

**玩法规则**：给定场景地台与 unlimited 积木形状库，自由拖放堆叠，无目标无失败。
**核心循环**：选积木 → 拖到场景 → 松手落位（简单物理稳定/网格吸附）→ 继续搭建 → 满意后拍照保存。
**难度梯度**：无（纯沙盒）；可解锁更多积木形状与场景地台。
**计分/结算**：无分数；作品进"我的相册"（本地保存合成图）。
**开发核心**：拖放手势 + Forge2D 轻物理（倾倒效果）或纯网格吸附（低幼档）。
**儿童化要点**：积木块全部带笑脸表情；清空按钮放二级菜单防误触。

### 6. 俄罗斯方块拼图（Relax Tetris）｜5+

**玩法规则**：经典方块拖放填满整行消除，但**去掉下落压力**——方块从底部托盘拖到场上任意位置（拼图化），或经典下落但速度恒定极慢。
**核心循环**：取方块 → 摆放 → 填满一行消除 → 分数与特效 → 继续。
**难度梯度**：拼图模式（无时间）默认；经典模式（慢速下落）大龄解锁。
**计分/结算**：行数即分数；**没有 Game Over**——堆到顶部时自动消除最底两行并提示"整理一下"。
**开发核心**：网格矩阵 + 形状旋转（状态矩阵）、消行判定、托盘随机生成保证可解。
**儿童化要点**：色块用角色库颜色体系；消行出彩虹特效 + 动物欢呼。

## 四、消除类

### 7. 动物连连看（Link Link）｜4+

**玩法规则**：棋盘成对动物图标，选中两张相同且连线转折 ≤ 2 次的即消除；全部消除过关；死局自动洗牌。
**核心循环**：点第一张（高亮）→ 点第二张 → 判定连通 → 消除动画 → 剩 0 张过关。
**难度梯度**：4×4 → 6×5 → 6×6；图案种类 6 → 10 种。
**计分/结算**：不限时（默认）；评星按提示使用次数。
**开发核心**：经典三段线连通检测（BFS，外圈留一圈空位辅助转弯）、死局检测 + 洗牌保证有解。
**儿童化要点**：默认无倒计时；提示按钮无限（家长可关）；动物图标 64px 大格。

### 8. 泡泡龙（Bubble Shooter）｜5+

**玩法规则**：底部发射台发射彩色泡泡，粘到顶部阵列，同色 3+ 相连即消除；上方悬挂泡泡失去连接一并掉落。
**核心循环**：瞄准（虚线辅助）→ 发射 → 吸附 → 消除/掉落 → 阵列下移一排 → 继续。
**难度梯度**：初始行数 4 → 6 → 8；颜色 4 → 6 种。
**计分/结算**：清除一波得星；**儿童档无失败线**——泡泡堆到警戒线时自动消除最底一排并提示。
**开发核心**：六边形网格吸附算法、同色 flood fill 消除、悬空连通性检测（与顶行 BFS 连通）。
**儿童化要点**：发射虚线延长到目标；大泡泡（半径 ≥ 24px）；发射速度慢。

### 9. 合成大西瓜（Merge Fruit）｜5+

**玩法规则**：顶部拖动确定落点放下水果，相同水果相碰合成更大一级，链式进化；**儿童档堆满线不清空即失败，而是自动消除最底层水果并继续**。
**核心循环**：瞄落点 → 放下 → 物理滚动碰撞 → 合成动画 → 大水果产生新目标期待。
**难度梯度**：水果等级 8 → 11 级；掉落速度慢/正常。
**计分/结算**：合成次数与最高等级即分数；图鉴（11 种水果进化链）常驻侧栏点亮。
**开发核心**：Forge2D 圆形刚体物理、同级碰撞检测合成、出生控制防直落重叠。
**儿童化要点**：物理时间缩放 0.7（慢动作）；水果全部画表情；进化时弹出图鉴卡。

## 五、操控类

### 10. 跳一跳（Hop Hop）｜4+

**玩法规则**：长按蓄力，松手小人跳向下一平台；落在中心连击加分；掉落不结束，原地重生继续。
**核心循环**：瞄准目测 → 按住蓄力（小人下蹲动画）→ 松手跳跃 → 落点判定 → 下一平台生成。
**难度梯度**：平台间距窄→宽；平台宽度大→小；辅助瞄准线开→关。
**计分/结算**：中心连击额外 +2；无死亡无清零，分数即历史累计。
**开发核心**：蓄力时长→跳跃距离映射、抛物线动画、落点区域判定（中心/普通/边缘）。
**儿童化要点**：默认显示落点虚线圈；失败重生时角色说"再来一次！"；平台用孩子熟悉的物品造型。

### 11. 迷宫大冒险（Maze）｜5+

**玩法规则**：控制小角色从起点走到发光的出口，沿途收集星星。
**核心循环**：滑动/虚拟摇杆移动 → 遇岔路选择 → 拾取星星 → 到达出口 → 下一迷宫。
**难度梯度**：迷宫 5×5 → 9×9 → 13×13；岔路复杂度递增。
**计分/结算**：星星全收集三星；无时间限制。
**开发核心**：递归回溯迷宫生成、墙格碰撞、足迹显示（走过的路留浅色痕迹）。
**儿童化要点**：出口持续发光 + 语音"我在这边~"；卡住 30 秒自动显示提示虚线。

### 12. 贪吃蛇（Snake）｜5+

**玩法规则**：滑动控制方向吃食物变长；**儿童档撞墙反弹不死、撞自己缩短 1 节不死**。
**核心循环**：滑方向 → 移动一格 → 吃到食物变长+得分 → 避开自己 → 目标分数过关。
**难度梯度**：速度 3 档（默认最慢）；地图 12×12 → 16×16。
**计分/结算**：达到本关目标长度即过关（如 10 节），非无限堆难度。
**开发核心**：网格队列移动、方向输入缓冲（防 180° 自杀）、食物生成避开蛇身。
**儿童化要点**：蛇头大眼睛、吃到食物吐舌头；食物 3 秒闪烁高亮。

## 六、模拟互动类

### 13. 宝宝钓鱼（Fishing）｜3+

**玩法规则**：水面下卡通鱼游动，点击即钓起进鱼篓；稀有的发光鱼需点 2 次。
**核心循环**：看鱼游 → 点击 → 钓起动画 + 入图鉴 → 期待下一条。
**难度梯度**：鱼速慢/快；普通鱼/发光鱼比例。
**计分/结算**：无失败；图鉴收集（8~12 种鱼）点亮是核心激励。
**开发核心**：贝塞尔路径游动动画、点击命中判定（判定圈外扩）。
**儿童化要点**：必钓中不脱钩；图鉴页每条鱼有名字语音介绍。

### 14. 小动物喂食（Feeding）｜3+

**玩法规则**：拖动食物到动物身边；每种动物有偏好食物（兔子吃萝卜、猫吃鱼），喂对开心动画，喂错动物摇头（不扣分）。
**核心循环**：看动物需求气泡 → 拖对应食物 → 反馈动画 → 下一只。
**难度梯度**：动物数 2 → 4 → 6；偏好提示气泡开→关。
**计分/结算**：喂饱 N 只过关；无失败。
**开发核心**：拖放目标区域判定 + 动画状态机（等待/开心/摇头）。
**儿童化要点**：需求气泡直接画食物图标（不识字也懂）；喂对后动物长大一点点（养成感）。

### 15. 美食小厨房（Mini Kitchen）｜4+

**玩法规则**：选菜谱 → 按高亮顺序完成步骤（点选食材 → 切 → 搅 → 煮，均为点击动画）→ 出餐给角色品尝并给出开心反馈。
**核心循环**：选菜 → 跟随高亮点击 → 半成品变化动画 → 完成 → 角色试吃反应。
**难度梯度**：步骤数 3 → 5 → 8；步骤提示开→关。
**计分/结算**：完成即得星；菜谱图鉴收集。
**开发核心**：步骤状态机 + 每步点击热点；无需真实物理。
**儿童化要点**：下一步永远高亮闪烁；植入生活习惯语音提示（"做饭前要洗手哦~"）。

## 七、自由创作类

### 16. 涂色小画家（Coloring）｜3+

**玩法规则**：线稿图分区，选择色板后点击区域填充；支持撤销；完成后保存。
**核心循环**：选颜色 → 点击区域 → 填充动画 → 换色继续 → 完成 → 保存/下一张。
**难度梯度**：区域数 5 → 10 → 20；"数字提示模式"（区域标色号）开→关。
**计分/结算**：无分数；作品保存进"我的画册"，家长中心可导出。
**开发核心**：预制分区蒙版（SVG path / 位图区域 flood fill）、撤销栈、导出合成 PNG。
**儿童化要点**：色板 12 色大圆块；填充必成功（不存在涂出界挫败）；自由涂鸦空白画布模式。

### 17. 贴纸乐园（Sticker Fun）｜3+

**玩法规则**：选场景底图（农场/海底/太空…），从贴纸库拖放贴纸，支持双指缩放旋转，自由拼贴。
**核心循环**：选场景 → 拖贴纸 → 摆放调整 → 保存作品。
**难度梯度**：无；贴纸库按主题包扩展（走下载系统）。
**计分/结算**：无分数；作品相册。
**开发核心**：手势变换（InteractiveViewer 定制）、贴纸层级管理、合成导出。
**儿童化要点**：贴纸点击有弹跳音效；一键清空需二次确认（防止辛苦作品被误删）。

### 18. 连线画（Dot to Dot）｜3+

**玩法规则**：按数字顺序从 1 连到 N，连完显示完整图案并自动播放填色动画。
**核心循环**：点当前数字点 → 线条延伸到下一提示点 → 全连完 → 图案揭晓庆祝。
**难度梯度**：点数 5 → 10 → 20；数字提示（下一目标点闪烁）开→关。
**计分/结算**：无分数；完成图案进画册。
**开发核心**：顺序命中判定（当前点 ≤ 48px 内即连上，自动吸附）、折线绘制、最终填色动画。
**儿童化要点**：当前应连的点持续放大闪烁；连错直接忽略（线不画出来），无音效警告。

## 八、知识类

### 19. 汉字小侦探（Character Detective）｜5+

**玩法规则**：每关给 1 个目标汉字 + 5~9 个形近干扰字，找出所有目标字；答对朗读该字与组词。
**核心循环**：语音念目标字 → 扫描找字 → 点击命中（翻牌亮起 + 朗读组词）/ 点错（抖动忽略）→ 全部找出过关。
**难度梯度**：干扰字相似度（宀字家族 → 笔画更多形近）、目标字数量 1 → 3、字数范围按年级。
**计分/结算**：无失败；按"连续答对"给星。
**开发核心**：形近字库 JSON（按部首/笔画分组，覆盖一年级常用字 ~800）、命中判定、TTS 或预录语音。
**儿童化要点**：点错零惩罚只轻微抖动；每关 5 个字以内防疲劳；每日推荐一组（家长中心可看"已认识的字"清单）。

## 附：开发优先级建议

| 优先级 | 游戏 | 理由 |
|---|---|---|
| P0（框架验证） | 翻牌记忆、打地鼠、拼图 | 逻辑最简，覆盖点击/拖拽/网格三类交互 |
| P1 | 连连看、涂色、跳一跳 | 开源参考多，玩法覆盖面广 |
| P2 | 合成大西瓜、泡泡龙、钓鱼 | 引入物理引擎与图鉴系统 |
| P3 | 其余 10 款 | 交互模式与前面重复度高，复用组件快速产出 |

每个游戏开发交付物 = 游戏本体 + `GameModule` 接口实现 + 素材包 manifest + 本文档对应条目的自测（按难度梯度逐档玩一遍）。
