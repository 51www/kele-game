# 《童趣游戏盒》素材资源指南

> 版本：v1.0 ｜ 配套：《儿童小游戏APP计划书》《游戏玩法设计文档》
> 目录结构：`shared/`（全局共用）+ `games/<游戏slug>/`（每游戏独立，各含一份 manifest.md 素材清单）

---

## 1. 目录结构

```
assets/
├── shared/                  # 全局共用素材（20 游戏共享，改一处全局生效）
│   ├── character-library/   # 角色库：12 个萌系动物 × 4 表情态
│   ├── ui/                  # 通用 UI：按钮三态/面板/星星/进度条/返回/设置
│   ├── audio/               # 音效与 BGM（全局统一音色）
│   └── fonts/               # 免费商用字体（霞鹜文楷等）
├── games/<slug>/            # 每个游戏一个目录，内含 manifest.md 素材清单
└── 素材资源指南.md            # 本文档
```

**规则：**
1. 素材文件命名小写下划线，PNG 一律透明底；同一素材只允许存在一份（放 shared），禁止复制到多个游戏目录。
2. 出血/留白：所有可点击素材本体四周留 10% 透明边距（对应 48px 触控热区规范）。
3. 提供尺寸即基准尺寸（@1x），导出时同时给 @2x（文件名加 `@2x` 后缀）。

## 4. AI 生成规范（风格统一的关键）

### 4.1 统一 Prompt 模板

```
cute cartoon {subject}, flat vector illustration style, thick rounded outlines,
bright pastel colors, kawaii happy face, simple shapes, centered,
pure white background, mobile game asset, no shadow, no text
```

- 角色/水果/食物全部走这个模板，仅替换 `{subject}`，保证全局风格一致。
- 需要"成对图"（找不同）时：先用模板出 A 图，再基于 A 图让 AI 做"改 3~5 处细节"的变体，人工核对差异点坐标。

### 4.2 必须 AI 生成（找不到合适现成素材）的清单

| 素材 | 所属游戏 | 原因 |
|---|---|---|
| 12 动物 × 4 表情态 | shared 角色库 | 需要同一角色多表情，现成套包做不到 |
| 11 级带表情水果进化链 | 合成大西瓜 | 风格连续性要求高 |
| 找不同成对图 ×10 | 找不同 | 市面无 CC0 成对儿童图 |
| 6 动物 × 3 互动态 | 小动物喂食 | 同角色多动作 |
| 场景底图 ×6 | 贴纸乐园 | 主题特定 |

### 4.3 已生成素材登记（M1 实际产出）

**生成方式**：AI 文生图（ImageGen），统一使用 §4.1 的 Prompt 模板，仅替换 `{subject}`，保证全局风格一致。

**统一 Prompt 模板（实际使用）**：

```
cute cartoon {subject}, flat vector illustration style, thick rounded outlines,
bright pastel colors, kawaii happy face, simple shapes, centered,
pure white background, mobile game asset, no shadow, no text
```
